Description du projet:
Une application d’aide au repérage des “Boîtes à clés” visibles sur l’espace public.

L’objectif du projet est de développer une application web mobile-first permettant de recenser des boîtes à clés visibles dans l’espace public.
Depuis un smartphone, un utilisateur peut prendre une photo, enregistrer la position GPS et ajouter un commentaire.
Les points collectés sont ensuite consultables sur une carte interactive. L’application répond à un besoin de repérage terrain et de centralisation d’informations, tout en restant accessible au grand public.
